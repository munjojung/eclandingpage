English Community - Local PDF Storage (Phase 1)

This folder is for administrator-PC-only PDF originals.
- Keep PDF files and manifest.json here locally.
- Do NOT commit PDF files or manifest.json to GitHub.
- Do NOT move this folder under public/.
- This folder is ignored by .gitignore except this README.

To manage files, start RUN_LOCAL_PDF_LIBRARY.bat and open local-pdf-library.html.
The browser asks you to choose this folder and grant read/write access.
